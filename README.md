# 📊 Telco Customer Churn: 통신 서비스 고객 이탈 예측 및 요인 분석

## 📌 프로젝트 소개
머신러닝을 활용하여 통신사 고객의 이탈 요인을 분석하고 예측하는 시스템입니다. 단순 모델링에 그치지 않고, 정부 과제 보고서 형식의 문서화와 실시간 대시보드 구현을 통해 실무적인 데이터 분석 프로세스를 완수했습니다.

## 📅 개발 기간
- 2025년 12월 26일 ~ 12월 29일 (1인 개발)

## ✨ 주요 기능
### 1. Layered Architecture 기반 파이프라인 설계
- **로직 분리:** 전처리, 학습, 예측, 시각화 영역을 역할별로 분리하여 유지보수성 증대
- **애플리케이션화:** Jupyter Notebook의 실험 코드를 Streamlit 기반 Python 앱으로 전환
- **모델 직렬화:** 학습된 모델과 스케일러를 `pickle`로 관리하여 재사용 가능한 구조 설계

### 2. 다각도 모델 실험 및 최적화
- **6종 모델 비교:** Logistic Regression, Random Forest, XGBoost, SVM 등 성능 비교
- **최적 모델 선정:** ROC AUC 지표를 기준으로 최적의 예측 성능을 가진 모델 채택
- **하이퍼파라미터 튜닝:** `GridSearchCV`를 활용한 성능 개선 및 과정 문서화

### 3. 데이터 시각화 및 실시간 예측 대시보드
- **비즈니스 인사이트:** 계약 유형별 이탈률, 주요 변수 분포도 등 그래프 중심 시각화
- **성능 검증:** 혼동 행렬(Confusion Matrix) 및 ROC AUC 차트 제공
- **실시간 예측:** 임의 데이터 입력 시 즉각적인 이탈 확률 예측 기능

### 4. 실무형 문서화
- 분석 배경부터 결과 해석까지 **정부 과제 보고서 양식**의 한글 문서(`.hwp`)로 정리

## 🛠 기술 스택
- **Language:** Python
- **Libraries:** Scikit-learn, XGBoost, Pandas, Matplotlib, Seaborn
- **Framework:** Streamlit
