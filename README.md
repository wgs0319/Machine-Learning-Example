# Telco_Customer

## 프로젝트 소개
머신 러닝을 이용한 통신 서비스 고객 이탈에 영향을 미치는 요인 분석 및 예측

## 개발기간
- 2025년 12월 26일 ~ 12월 29일

## 개발 인원
- 1인 개발

## 주요 기능
1. Layered Architecture 기반 구조 설계로 유지보수 편의성 증대
 - 데이터 전처리, 모델 학습, 예측 로직, 시각화 영역을 역할별로 분리하여 구성
 - Jupyter Notebook에서 검증한 분석 로직을 Streamlit 기반 Python 애플리케이션으로 분리 구현
 - 모델, 스케일러를 pickle 파일로 저장하여 재사용 가능한 예측 구조 설계
2. 머신러닝 파이프라인 구축 및 프로젝트 체계적 관리
 - 데이터 로딩 → EDA → 전처리 → 모델 학습 → 성능 평가 → 최종 모델 선정까지
머신러닝 전체 프로세스를 단계별로 정리 및 관리
 - Logistic Regression, KNN, Decision Tree, Random Forest, XGBoost, SVM
총 6개 모델 성능 비교 및 ROC AUC 기준 최적 모델 선정
 - GridSearchCV를 활용한 하이퍼파라미터 튜닝 및 성능 개선 과정 문서화
3. 대시보드 기반 시각화를 통한 데이터 분석 편의성 증대
 - 고객 이탈 비율, 계약 유형별 이탈률, 주요 변수 분포를 그래프 중심 대시보드로 시각화
 - ROC AUC 비교 차트, 혼동 행렬(Confusion Matrix)을 통해
모델 성능을 직관적으로 확인 가능
 - 임의 고객 데이터를 입력하여 실시간 이탈 확률 예측 기능 구현
4. 실무 문서화 경험 (정부 과제 보고서 형식)
 - 분석 배경, 데이터 설명, 모델링 과정, 결과 해석을 정부 과제 보고서 양식의 한글 문서로 정리
